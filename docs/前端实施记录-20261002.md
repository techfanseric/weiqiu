## 已实现

- 独立 `#/display` 展示路由：1920 × 1080 设计基准，按视口等比适配 16:9 屏幕，包含实验概览、设备区域、检测结果和样本时间线。正式路由继续走已有登录校验；显式演示无需登录。
- 重新制作机台视觉：使用 imagegen 内置工具生成新的透明底设备图，叠加独立 SVG 分区和状态动效；原始设备图仅作结构参考。双机械臂、两条轨道、反应容器、左右模块分布可辨认。图为概念示意，模块内部细节及热区需与现场核准，不能充当精确数字孪生。
- 同流程 1–10 样本错峰时间线：同一时间可有反应与取样检测，清洗保留 3 次独立实例；完整时间跨度自动适配，行头始终显示当前动作。演示设置支持样本数、暂停/异常和进度滑块。
- 检测图表明确所属样本及检测时间。无结果、无质量规则分别给出空态与待判定提示，不根据示例数值自行判断合格。
- 五类状态问答：实验、步骤、数量、时间、质量；使用当前快照生成回答。浏览器支持时可按住按钮或空格键收音、松开识别，并以系统 TTS 播报。也可用五个问题按钮验证字幕与高亮。无历史聊天，未实现自由聊天或设备控制。
- 字幕放在机台下方的说明区，不覆盖样本时间线。切换批次或数据失效会取消旧回答；声音可静音；未支持识别、未授权麦克风或识别失败均有提示。
- 操作台采用蓝白主题及官网 SIAT Logo，保留原菜单、业务组件和操作接口，增加大屏入口。统一表格、按钮、表单、节点、图表、间距和字体；优化首页设备区域布局。
- 清理首页“无数据自动填充旧示例”的逻辑，区分本地预览、缓存和已接收推送。刷新请求本身不再伪造更新时间。去掉两处未被调用且引用不存在 API 的 `getUser/getRole`，修复原类型错误。
- 新增完整快照适配器，拒绝无效数据、超出 10 个样本、重复步骤 ID、无关样本结果、旧批次及乱序消息。缓存保持历史时间；没有有效数据不回退演示。
- 大屏 MQTT 连接为只读，不发送应用心跳或设备控制指令；本地演示完全不连接 MQTT。原控制台连接继续沿用原协议。

## 当天后续界面调整

- 登录字段去除隐藏标签留下的空白列，使输入框与按钮同宽对齐。保留可访问名称和自动填充语义。
- 登录校验提示改为 12px 字号、18px 行高和柔和红色；字段预留提示空间，必填及密码长度错误出现、清除时布局保持稳定。
- 字幕条固定 65px 高度，标题和关闭按钮固定两端；长内容以 28px/s 横向循环，短内容静止。至少完整滚动一遍后才自动消退，悬停或聚焦暂停，并适配减少动态效果偏好。
- 关闭按钮采用 76 × 32px 的紧凑外观与扩大的透明点击范围，不撑高字幕区；再次提出相同问题会重新开始字幕。
- 演示设置增加布局选择。布局二将机台放到右侧并跨越实验标题行，概览与检测信息放左侧，时间线通栏；三个区块标题前不再显示 01/02/03，机台区域编号保留。
- 布局选择写入 URL，切换不重置演示参数；仅演示模式提供布局二，真实模式仍使用布局一。

以上调整已通过浏览器检查；最近一次布局标题与登录提示调整后，生产构建和类型检查通过。布局检查包含 1 / 10 样本、暂停、结果空态和 1366 × 768 视口；字幕检查包含长短内容、自动消退、重复提问及减少动态效果。

## 本地启动与入口

建议 Node 24（本次验证），至少满足既有 JSX 插件声明的 Node 22.12 下限。

```sh
cd ~/weiqiu/app
npm ci --ignore-scripts --no-audit --no-fund
npm run dev -- --host 127.0.0.1
```

| 入口 | 用途 |
| --- | --- |
| `http://127.0.0.1:9006/#/display?mode=demo` | 完整演示大屏，常驻演示标识 |
| `http://127.0.0.1:9006/#/display?mode=demo&layout=machine-right` | 布局二：机台在右侧并跨越实验标题行 |
| `http://127.0.0.1:9006/#/display?mode=demo&samples=10` | 10 样本展示 |
| `http://127.0.0.1:9006/?preview=1#/` | 原操作台的本地视觉预览；仅开发构建启用，HTTP 写操作和 MQTT 已禁用 |
| `http://127.0.0.1:9006/?preview=1#/login` | 登录表单及校验反馈预览 |
| `http://127.0.0.1:9006/?preview=1#/display` | 开发时查看断线空态，不连接设备 |
| `#/display` | 正式数据模式；保留登录校验，等待有效快照 |

操作台预览中的表格读取使用本地空集合/示例列表，保存和设备操作被明确阻止。它用于检查 UI，不代表业务接口完成联调。正式构建不会以 `preview=1` 绕过登录或拦截正常接口。未部署到用户提供的线上站点。

## 数据接入

现有消息未提供足够的多样本步骤与结果归属信息，因此没有将旧 PCR 示例或无归属指标强行映射到机台。新增协议详见 `docs/展示数据契约-v1.md`。

现有 MQTT 主题 `/data/notification/changed` 可承载 `{ type: 'display', data: snapshot }`。这里的 `display` 是本次新增的前后端约定，尚不能声称线上服务已支持。可选 `VITE_DISPLAY_SNAPSHOT_URL` 接收同源 GET 快照；默认留空，不猜测已有接口。原团队提供确认后的接口、站号、微球流程与脱敏消息后完成联调。

## 验证

- `npm run typecheck`：通过，含原工程全部 Vue/TypeScript 文件。
- `npm test`：9 项状态与问答测试通过，覆盖 1/5/10 样本、反应内检测、清洗循环、乱序/重复、跨批次清空、异常载荷、断线/过期及无依据不判定质量。
- `npm run build`：通过；字体与图像随构建输出，CSS 使用相对字体路径，支持 `/weiqiu/` 子目录。
- ego 浏览器：检查五样本、十样本、单样本、暂停、断线空态、质量问答及高亮；十样本行头无横向溢出。演示页面没有外部资源依赖，断线预览没有后端请求。修复了仅变更 URL 中 `samples` 参数时未更新行数的问题。
- 生产产物在本地 `/weiqiu/` 路径另行检查；核对字体、图片和无需登录的演示入口。
