# 助手四状态动效

日期：2026-10-23。

四款生图形象统一接入 `app/src/display/AssistantMascot.vue`，使用原透明图与 CSS 变换、状态装饰层组合，不改变源图。

| 状态 | 动效 |
| --- | --- |
| 待机 | 轻浮、呼吸缩放与柔和光晕 |
| 聆听 | 微微侧倾、前探，两道扩散声波 |
| 思考 | 轻摆、环绕光点 |
| 说话 | 小幅点头律动，侧边五段音量条 |

这些是视觉状态指示，不是口型同步或音频幅度驱动的动画。

## 页面使用

点击右下角“问问助手”，在卡片底部选择形象与动效。可分别选择“待机、聆听、思考、说话”，或开启每三秒切换一次的循环演示。“自动”跟随 `useVoice` 实际问答状态。

动效预览不调用录音或语音播报；页面和语音入口均标注预览。真实问答优先，提问或按住说话将清除预览并恢复自动模式；收起助手卡片也退出预览。组件卸载时清除循环计时器。

欢迎头像、语音入口、字幕头像共用组件。系统启用减少动态效果时停止动画，保留文字、声波轮廓和状态图形。
