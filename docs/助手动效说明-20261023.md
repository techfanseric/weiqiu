# 助手四状态动效

日期：2026-10-23。当前四款均采用分层表情，保留此前整体轻动方案供页面对比。图文效果与v2.1.0 升级说明见 [版本升级说明](版本升级说明-20261023.md)。

## 当前实现：分层表情

四款共用 `app/src/display/AssistantMascot.vue` 入口，由 `LayeredAssistant.vue` 驱动头部、身体、双臂与 SVG 五官。`AssistantLayer.vue` 和 `assistantLayers.ts` 统一透明 PNG 的留白与尺寸，以等比缩放和位移摆放；源图像素不变。单侧手臂镜像构成双臂，白瓷兼容入口为 `CeramicAssistant.vue`。

| 状态 | 分层动作 | 装饰提示 |
| --- | --- | --- |
| 待机 | 眨眼、呼吸、轻微摆臂 | 柔和光晕 |
| 聆听 | 专注表情、侧头、抬手 | 扩散声波 |
| 思考 | 视线上移、手臂靠近下巴 | 环绕光点 |
| 说话 | 三种嘴型交替、小幅点头、交替摆臂 | 五段律动条 |

手臂状态姿势以 550ms 过渡。嘴型按说话状态循环，不是音素同步或音量驱动。

## 页面使用与状态优先级

点击右下角“问问助手”，可切换蓝晶伙伴、白瓷伙伴、轻绘精灵、晶透助手，以及“分层表情 / 整体轻动”。可单独选择四状态，或每三秒循环；“自动”跟随实际问答状态。

预览不调用录音或语音播报，页面和语音入口均标注预览。真实提问或按住说话清除预览，恢复自动；收起卡片也退出预览。停止循环恢复自动，组件卸载时清除计时器。欢迎头像、语音入口和字幕头像共用组件。

链接使用 `assistant=classic|ceramic|illustrated|glass`；`assistantMotion=whole` 为整体轻动，省略为分层版；兼容旧白瓷链接 `ceramicMotion=whole`。切换动画方式时清理旧参数。

系统启用减少动态效果时停止动画，保留静态姿势、文字与状态图形。
