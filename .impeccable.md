# Design Context

Confirmed by user acceptance of the transcript-based project analysis and subsequent brand/material instructions, 2026-10-02.

- Audience: visitors watching a 55-inch laboratory display from 2–3 m; researchers using the existing console on laptops.
- Jobs: understand current experiment, parallel sample stages, equipment activity and particle results. Researchers retain established configuration and control workflows.
- Brand: 中国科学院深圳先进技术研究院 / SIAT. Voice: 严谨、清晰、沉着. Light blue/white institutional laboratory visual, with restrained deep blue official identity. Source assets and color provenance are archived.
- Visual direction: scientific exhibition panel. A freshly created machine overview is the visual anchor, paired with precise timelines and readable data. No raw supplied device imagery in pages.
- Typography procedure: default reflex candidates Inter, IBM Plex Sans, Space Grotesk rejected. Google Fonts catalog reviewed; Manrope's clear open numerals fit instrument readouts, paired with Noto Sans SC for Chinese exhibit captions and dense operator UI. Self-host fonts for local display reliability.
- Accessibility: state always includes words, keyboard-operable controls, reduced motion, live/unknown/demo distinction. Critical information never requires hover.
- Scope: existing Vue application, standalone read-only display, light console, five bounded status questions; no experiment control via speech.
